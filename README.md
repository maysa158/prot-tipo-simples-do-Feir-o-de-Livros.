# Feirão do Livro — Aula 17

Aplicativo React Native + Expo desenvolvido a partir do desenho da cliente da Aula 17.

## Fluxo implementado

- Início → Ver acervo → Acervo
- Acervo → toque em um livro → DetalheLivro
- Início → Como participar → ComoParticipar
- Acervo, DetalheLivro e ComoParticipar → Voltar

O Acervo possui 5 livros fictícios. Ao tocar em um livro, o objeto daquele livro é enviado para a tela de detalhes por parâmetro de navegação.

## Como executar

```bash
npm install
npx expo start
```

Abra no Expo Go ou emulador.

## Fonte da atividade

Código desenvolvido seguindo o requisito e a lógica de navegação apresentados na Aula 17 — UC 23 Mobile (Parte 2).
